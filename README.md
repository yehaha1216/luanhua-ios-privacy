# 嘟嘎记账 - 隐私政策与用户协议

这是嘟嘎记账（DugaLedger）隐私政策与用户协议的静态站点，可托管在 GitHub Pages 上。

## 文件说明

- `index.html` - 中英文隐私政策
- `terms.html` - 中英文用户协议
- `icon.png` - 嘟嘎记账应用图标
- `README.md` - 本文件

`index.html` 与 `terms.html` 顶部互相链接；两页使用同一套语言切换，通过 `?lang=en` 查询参数传递语言，不写入浏览器本地存储。中文页面不需要该参数。

## 部署到 GitHub Pages

1. 在 GitHub 上创建仓库并推送本目录内容。
2. 进入仓库的 Settings > Pages。
3. 在 Source 下选择部署分支（通常是 `main`）和根目录。
4. 保存后等待 GitHub Pages 生成站点。

## 本地预览

直接在浏览器中打开 `index.html` 或 `terms.html` 即可预览；页面不需要构建步骤。
